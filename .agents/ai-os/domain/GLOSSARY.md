# Domain Glossary

This glossary defines the canonical business terminology utilized across the MAD Entertrainment platform.

---

* **Event**: A scheduled entertainment gathering (e.g. DJ Night, Concert, Festival) configured for public or VIP booking.
* **Ticket Profile**: The template specifying ticket pricing, tier categories, and initial allocation limits for a particular event.
* **Seat Layout**: The grid representation of physical seats (specifying rows and numbers) for seat-based booking events.
* **Booking**: The transaction record detailing a customer's reservation and payment for tickets.
* **Reservation Lock**: A temporary block placed on specific seats or general admission tickets to allow a customer to finalize payment.
* **OTP (One-Time Passcode)**: A 6-digit numeric verification token generated for passwordless magic link email authentication.
* **Coupon**: A promotional discount code that can be applied to a booking to reduce its payable total.
* **Refund**: The cancellation process that returns payment totals to the customer's payment method.
* **Ticket**: An admission pass containing a unique barcode/QR code representing a confirmed booking.
* **DJ Operator**: An artist or performer allocated to perform at one or more scheduled events.
* **Admin**: An internal system user authorized to perform operational tasks (e.g. event management, refunds, barcode scanning).
