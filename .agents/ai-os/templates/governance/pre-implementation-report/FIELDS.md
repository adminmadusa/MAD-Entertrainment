# Pre-Implementation Report Fields

* **currentBranch**: Active git branch.
* **gitStatus**: Output of git status command.
* **filesToChange**: Array of file targets.
* **reasonForChange**: Explanation for task.
* **riskLevel**: High/Medium/Low rating.
* **patchSummary**: Description of logic updates.
* **verificationPlan**: Steps to confirm success.
* **rollbackPlan**: Steps to restore baseline.
