# ADR Template

* **Template ID**: TMP-DOC-001
* **Purpose**: Defines standardized layout for Architecture Decision Records (ADRs).
* **Output Type**: Markdown file.
* **Version**: 1.0.0
* **Required Sections**:
  - Unified metadata header
  - Title: ADR [ID] — [Name]
  - Status (proposed/accepted/rejected/superseded)
  - Context and Problem Statement
  - Decision Drivers
  - Considered Options
  - Decision Outcome (chosen option + justification)
  - Consequences (pros and cons)
* **Optional Sections**: References.
* **Completion Criteria**: Requires unanimous approval from the architecture review board prior to accepted transition status.
