# Template Library

Welcome to the Template Library of the AI Operating System. This library defines the standardized presentation structures and output layouts for artifacts generated by AI skills and prompts.

Templates are presentation-only and contain no workflow execution logic; they ensure that all emitted artifacts conform to metadata and formatting rules defined in the Standards and Governance layers.

## Directory Inventory

The Template Library contains the following folders:
- [README.md](file:///Users/admin/Desktop/MAD%20Entertrainment/.agents/ai-os/templates/README.md) — This entry point and inventory.
- [REGISTRY.md](file:///Users/admin/Desktop/MAD%20Entertrainment/.agents/ai-os/templates/REGISTRY.md) — The catalog mapping active templates.

### Templates
- **audit/repository-audit-report**: Layout for repository naming and hygiene audits.
- **planning/implementation-plan**: Layout for pre-implementation plans.
- **implementation/bug-fix-report**: Layout for bug resolution logs.
- **governance/pre-implementation-report**: Layout for branch manual verification gates.
- **documentation/adr**: Layout for Architecture Decision Records (ADRs).

## Precedence & Dependencies
All files in the Template Library are Tier 8 (Templates) artifacts. They represent the presentation boundary of the AI OS. They depend on all other layers (Foundation, Repository, Domain, Architecture, Standards, Patterns, Anti-Patterns, Governance, Validation, Skills, and Prompts).
